1. Sumar Executiv

Proiect de digitalizare completă a serviciilor Agenției Naționale pentru Sport (ANS): 13 module funcționale interconectate (portal public, registratură/DMS, registre sportive, arhivă, BI, chatbot AI propriu, aplicații mobile), pe infrastructură Cloud Privat Guvernamental (Azure Stack Hub), cu componente COTS licențiate perpetuu și dezvoltări custom.

Obiective cheie

Obiectiv generalDigitalizarea end-to-end (nivel de sofisticare 4/5 – tranzacție completă online) a serviciilor publice ANS pentru federații, cluburi, sportivi, antrenori, baze sportive și cetățeni.
Model de livrareSoluții COTS (licențe perpetue, utilizatori nelimitați) pentru Portal, DMS/Registratură, LMS (CNFPA), Arhivă, Securitate + dezvoltare custom pentru module specifice (Registre Sportive, Anuar, Galeria Marilor Sportivi, BI, Chatbot, Mobil).
Infrastructură țintăCloud Privat Guvernamental (CPG) pe Azure Stack Hub, arhitectură cloud-native, containerizare Kubernetes, DR activ-pasiv (RPO<15 min, RTO<1h).
Constrângere AIInterzisă explicit integrarea cu ChatGPT/Gemini/DeepSeek în Chatbot, Portal și modulul BI — obligatoriu model NLP/AI propriu, antrenabil, găzduit intern.

3. Arhitectură Software (vedere pe straturi)

Arhitectură API-first, cloud-native, cu backend complet decuplat de interfețe. Toate straturile comunică prin API-uri documentate OpenAPI 3.x, printr-un API Gateway central.

Strat 1 — Canale de acces (Front-end)

Portal Public ANS (web, responsive, WCAG 2.1 AA) Aplicație mobilă Portal (Android/iOS) Aplicație mobilă DMS internă (biometric, privată) Chatbot/Asistent Virtual (NLP propriu) Panouri interne Federații/Cluburi/CNFPA/Galeria Sportivilor
▼ API Gateway (REST/SOAP/GraphQL/gRPC · OAuth2/OIDC · JWT · rate limiting · OpenAPI 3.x)

Strat 2 — Integrare & Orchestrare

API Gateway centralizat ESB / middleware integrare Webhook-uri & Message Queues (RabbitMQ/Kafka) Circuit Breaker / Retry / Event-driven Vault gestionare secrete
▼

Strat 3 — Module aplicative (business logic)

Portal Public (COTS) Registratură/DMS (COTS + BPMN 2.0 workflow) Registrul Sportiv (Federații/Cluburi) Registrul Sportivilor & Antrenorilor Registrul Bazelor Sportive Anuarul Sportului Galeria Marilor Sportivi (3D/tur virtual) CNFPA (LMS COTS) Arhivă electronică (OAIS) Modul Administrativ Chatbot NLP propriu Rapoarte BI/DWH
▼

Strat 4 — Date

SGBDR criptat (MySQL/MSSQL/Oracle/PostgreSQL) Data Warehouse / Data Mart (star schema) ETL Depozit documente + Full-Text Search + OCR/ICR Storage arhivă (300dpi, PDF/A, XML metadate)
▼

Strat 5 — Securitate transversală

IAM/SSO/MFA (OIDC/SAML/SCIM 2.0) RBAC granular WAF (2× HA) Firewall NGFW cloud (2× HA) Anti-DDoS (SaaS, SLA 99,9%) SIEM/XDR + Vulnerability Scanner EDR/MDR Plus + SOC 24/7
▼

Strat 6 — Infrastructură Cloud

Cloud Privat Guvernamental — Azure Stack Hub (IaaS) Virtualizare Bare-Metal (Tip 1, multi-OS) Orchestrare Kubernetes multi-cloud + GitOps/Terraform Disaster Recovery activ-pasiv (RPO<15min, RTO<1h) 20 conexiuni VPN IPSec

4. Module Funcționale & Task-uri de Dezvoltare

Pentru fiecare din cele 13 module: scop, cerințe cheie și task-urile principale de proiect (analiză → dezvoltare → integrare → testare).

1Portal Public ANS

Front-office unic: Servicii Electronice Complete/Parțiale, Spațiu Privat Virtual (SPV), formulare cu pre-populare, notificări status.

COTSSOAP/RESTForm Builder
  • Analiză 11 servicii publice de digitalizat + mapare flux "grad 4/5"
  • Configurare Form Builder + generare PDF identic formular oficial
  • Implementare SPV ("My Account") + istoric interacțiuni
  • Integrare notificări email automate pe status solicitare + feedback/rating
  • Autentificare cu email ca identificator unic + SSO către IAM
  • Testare compatibilitate cross-browser (Edge/Firefox/Safari/Chrome)

2Registratură – Management Documente (DMS)

Sistem de ticketing instituțional: depozit/captură documente, registratură electronică, motor workflow BPMN 2.0.

COTSBPMN 2.0OCR/ICR
  • Configurare organigramă instituțională + reguli numerotare automată (Tabel metadate)
  • Implementare Full-Text Search + OCR asincron (Office/XML/PDF/imagini) + ICR scris de mână
  • Editor WYSIWYG colaborativ cu Track Changes/Versioning (CRDT/OT)
  • Calcul automat termen legal L544/2001 + gestionare suspendare termen
  • Proiectare fluxuri BPMN: aprobare/avizare, escaladare automată, delegare pe concediu
  • Cod unic de verificare document pentru petent + integrare email atașamente
  • Export JSON/DOCX/PDF-A + rapoarte Excel/CSV/PDF

3Registrul Sportiv – Federații & Cluburi

Emitere/gestiune Certificat de Identitate Sportivă (CIS), afiliere, calendar competițional, transferuri.

Legea 69/2000Imprimeria Națională
  • Model de date federații/cluburi/asociații județene/ligi (istoric complet denumire/sediu)
  • Flux emitere/suspendare/retragere CIS + interfață tipărire Imprimeria Națională
  • Modul viză medicală cu notificare expirare + blocare automată participare competiții
  • Flux transfer sportivi (definitiv/temporar) cu verificare eligibilitate
  • Evidență taxe afiliere cu blocare acces la neplată
  • Integrare date radiere cluburi (ANAF, judecătorii) – consultare/verificare
  • Integrare obligatorie cu Registratura Electronică + Motorul de Workflow

4Registrul Sportivilor & Antrenorilor

Registru Național (Ordin ANS 302/2023), administrat cu INCS. >100.000 sportivi, 4.619 cluburi.

CNP unicGDPR
  • Model de date cu CNP ca identificator unic + reguli minori/tutore legal
  • Import în masă Excel/CSV + validare/deduplicare
  • Cont public sportiv: transfer club, dezafiliere, istoric competiții
  • Serviciu "Pașaport Sportiv" & "Pașaport Antrenor" (generare document + acces public)
  • Flux certificare "antrenor emerit" + asociere antrenor–club–federație–bază sportivă
  • Mecanism ștergere date conform GDPR (dreptul de a fi uitat)

5Registrul Bazelor Sportive

63 baze omologate; omologare realizată de federații, ANS are rol de coordonare.

9 categorii B1–B9
  • Model de date UPS: construcții acoperite, terenuri exterior, construcții complementare
  • Workflow ciclu de viață (inițiere→validare→aprobare→publicare) fără ștergere fizică
  • Diferențiere update minor vs. major (statut juridic/stare funcțională)
  • Integrare cu direcțiile sportive județene + Consilii Locale/Județene
  • Asociere bază sportivă ↔ federație ↔ antrenor/club

6Anuarul Sportului

Publicație oficială anuală generată automat, sursă pentru Institutul Național de Statistică.

  • Motor de generare automată pe date validate (fără input manual) + recalculare la modificări sursă
  • Clasamente multi-dimensionale: federație, județ, individual, unitate sportivă, medalii, vârstă
  • Stări document: Provizoriu / Validat / Oficial + versionare istorică
  • Almanah Online: hartă interactivă România + profil public automat sportiv/antrenor
  • Export PDF/Excel + integrare date către INS

7Galeria Marilor Sportivi

>10.000 artefacte (~7.000 speciale, Legea 182/2000, Legea 311/2003).

QR3D/Tur virtual
  • Modul bilete online cu cod QR + capacitate configurabilă per interval orar
  • Tur virtual interactiv + ghid audio + integrare Arhiva TVR
  • Pipeline digitizare 2D (min. 12MP JPEG/PNG web + TIFF arhivă) și 3D "spin view"
  • Configurator expoziții digitale multilingv (RO/EN)
  • Integrare cu aplicația mobilă (rezervări, tur digital)

8CNFPA (Formare/Certificare Antrenori)

Platformă LMS COTS acreditată Ministerul Muncii, fluxuri certificare tripartite ANS-Federație-CNFPA.

LMS COTSSCORMWCAG 2.1
  • Configurare Authoring Tool + min. 25 șabloane interactive + export SCORM
  • Fluxuri: certificat absolvire, carnet antrenor, clasificare profesională, recunoaștere UE/SEE
  • Bancă de întrebări + evaluări complexe + generare AI lecții/teste
  • Asistent de învățare AI cu hartă de cunoștințe (model propriu, nu ChatGPT/Gemini)
  • Integrare monetizare (PayPal/Stripe) + roluri Admin/Tutor/Student/Super Admin ANS

9Arhivă Electronică

Conform ISO 14721 (OAIS), ISO 15489, ISO 27001. Digitizare 500 din 2.274 ml (≈2,5 mil. pagini).

OCR 300dpiPDF/A
  • Proiectare depozit digital + indexare automată (CNP, tip document) + interoperabilitate DMS
  • Definire flux fizic: preluare→grupare→dosare (max 250 file)→legare cod de bare→inventariere
  • Pipeline digitizare (min 300dpi, PDF searchable) + indexare full-text OCR + export XML (max 5 indecși)
  • Obținere autorizații: Arhivele Naționale, ISU, Autoritatea Rutieră Română
  • Implementare SLA livrare: 4h digital urgent / 24h-5 zile fizic + condiții microclimat
  • Plan migrare ulterioară către Cloudul Guvernamental

10Modul Administrativ

Management utilizatori/roluri, entități, audit, notificări.

2FAAudit trail
  • Gestiune utilizatori/permisiuni granulare per modul + 2FA (Authenticator/Email/SMS)
  • Dashboard-uri BI interne (sportivi activi, evoluție)
  • Integrare OCR pentru extragere date CI/cazier judiciar
  • Motor notificări configurabile (expirare viză, termene)
  • Audit complet: IP, browser, endpoint, valori anterioare/noi, autentificări eșuate

11Chatbot / Asistent Virtual

NLP+NLG propriu, 24/7, interzis ChatGPT/Gemini/DeepSeek.

AI propriuSR ISO/IEC 42001
  • Selecție/antrenare model NLP local pe corpus specific ANS (registre publice)
  • Detectare stare emoțională utilizator + interacțiune vocală
  • Verificare preliminară completitudine documente încărcate
  • Elaborare metodologie de gestionare a riscurilor AI (aliniere SR ISO/IEC 42001)
  • Integrare cu Portal, Aplicație mobilă și modulul BI (interogare NL)

12Rapoarte Business Intelligence

Înlocuire rapoarte manuale .xls/.doc de la Direcții Județene, cluburi, INCS, CNFPA, Galeria Sportivilor.

ETLStar SchemaGIS
  • Proiectare Data Warehouse/Data Mart (star schema) + pipeline ETL automatizat
  • Hartă GIS interactivă + distribuție teritorială
  • Configurator vizual rapoarte fără SQL + livrare automată email (zilnic/săpt./lunar)
  • Modul analitic DMS: scoruri Efficiency/Delay/Throughput/Approval Quality + grafice avansate
  • Modul AI/NLP interogare BI (text→SQL, read-only, model local)

13Aplicații Mobile (Android/iOS)

App public portal + app DMS internă dedicată (biometric).

AndroidiOSBiometric
  • App publică: Registrul Sportiv, CIS, calendar competiții, ghid baze sportive, asistent virtual
  • Modul Muzeu mobil: rezervări, bilete QR, tur digital
  • Modul CNFPA mobil: catalog cursuri, player, certificate/carnet digital
  • Modul Finanțare/Sponsorizare: flux digital granturi + status timp real
  • App DMS internă: autentificare biometrică, scanare cameră, notificări push, criptare locală
  • Publicare conform politicilor Google Play/Apple Store (responsabilitate prestator)
